Frequently asked questions

What is a MetaPhlAn table?

The merged output of MetaPhlAn, the taxonomic profiler, with one row per clade and one column per sample. Abundances are relative (percent).

How do I create one?

Run MetaPhlAn on each sample, then combine them with merge_metaphlan_tables.py. See the MetaPhlAn documentation.
