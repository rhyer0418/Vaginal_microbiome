Projects

Each project is a self-contained study with its own samples, metadata and reference. The framework is:

  • Project ID, a short unique code, e.g. RAVEL2011
  • Reference, DOI and citation
  • Cohort, population, number of participants, inclusion criteria
  • Sampling, sample site, collection method and storage
  • Sequencing and profiling, platform, MetaPhlAn version and database
  • Phenotypes, clinical variables with definitions
  • Ethics and access, approval reference and data-sharing terms
